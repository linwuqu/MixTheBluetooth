# 业务工作流目录（业务说明书）

架构设计见 [../架构/CONTENT.md](../架构/CONTENT.md)，编号为业务空间独立主序列。

## 3. 沉淀顺序

1. 需求提出 → 对话对齐（不写文档）。
2. 架构阐述与迭代（过程文档，施工后退役）。
3. 施工完成后：沉淀业务说明书到本目录（本文件模板见 doc-writer skill）。
