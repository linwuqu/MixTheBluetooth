# 演进史（做了什么）

> 说明：回答"项目是怎么走到今天的"。按阶段归纳（不是提交列表），每次结构性变更追加一节。
> 当前分支：`dev-2.1-BypassAuth`。

## 阶段 0：最小闭环（2026-07 上）

- 建立 `migratedev` 模块与扩展版 MVVM 骨架：`UI → Translation → Orchestrator ↔ DecisionCore → Port`。
- 第一个最小业务闭环：**登录/注册/自动登录**（`AuthDecision` 状态机 + AuthPort）。
- 本地会话用 Tink AES-GCM 加密存 SharedPreferences；远端用 Retrofit。
- 提交线索：`653eba2` 最小登录闭环 + 自动登录、`a9a61fe` 完整参考文件。

## 阶段 1：父子编排器（2026-07 中）

- 把业务域打通到统一父流程：`RootWorkflow` 管理子 Translation 的生命周期、页面栈、跨域内容交换。
- 子业务之间只通过 `Output → RootEvent` 单向上报，不互读状态。
- 提交线索：`4512299` 统一 RootWorkflow.orchestrator 管理；文档 [01-父子编排器](../架构/01-父子编排器.md)。

## 阶段 2：端口挂载分离与词汇修订（2026-07 下）

- 能力端口与业务适配器分离（架构 03）：蓝牙扫描独立为原生 `BluetoothLeScanner` 能力（架构 02），HC 库只留连接。
- **词汇统一与契约收尾**（架构 04）：首版把 Command/Result 中间词汇下沉到蓝牙域；修订版（2026-08-06）删除 `CommandPort`，执行器改函数类型；`BluetoothCommand/Result → BluetoothEffect/Event`，**全库 Command/Result 词汇清零**。
- 扫描保持简单版：单活动扫描互斥（实测确认无竞态、限流场景有限），并沉淀竞态回归测试。
- 提交线索：`a577701` 端口挂载分离、`a4ee129` 词汇统一修订；文档 [03](../架构/03-端口挂载与业务适配器.md)、[04](../架构/04-词汇统一与契约收尾.md)。

## 阶段 3：UI 重写与流建模（2026-08 初）

- UI 按架构 05 重写：Route 业务转移 / Screen 纯呈现 + 组件拆分与 Preview。
- 流建模（架构 06）：三类流（UI 态流 / 数据流 / 事件流）如何回答抗压与低能耗；刷新链路 `isRefreshing + 共享扫描` 被证伪后回退。
- 提交线索：`5d23fac` UI 重写、`6ebdc65` 刷新链路与流建模。

## 阶段 4：调试离线会话（当前，2026-08）

- BypassAuth：DEBUG 构建下服务器不可达时注入假会话，直接进入扫描页，便于纯蓝牙调试。
- 提交线索：`7bd87c6`。
