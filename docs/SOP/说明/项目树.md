# 项目树（覆盖面）

> 说明：本文是**覆盖面快照**，回答"这个项目有哪些部分、各部分职责是什么"。

## 0. 一句话

`MixTheBluetooth` 是 Android 应用：用 BLE 蓝牙连接硬件采集 CGM（连续血糖监测）数据流，上传远端做模型推理，把预测结果以"类 Dexcom / LibreView"风格展示。当前主战场是 `migratedev` 模块（MVVM 状态机重构版）。

## 1. 仓库布局

```
MixTheBluetooth/
├── migratedev/            ← 主战场：MVVM 状态机重构（本说明的重点）
│   ├── src/main/kotlin/com/biosensor/migratedev/
│   ├── src/test/          ← 单元测试（75 个，19 套件）
│   └── src/androidTest/   ← 仪器测试（Keystore/Tink 会话闭环）
├── bluetoothlibrary/      ← HC 蓝牙库（旧版，迁移中被包一层 Client 使用）
├── app/                   ← 旧版主工程（Java，待退役）
├── basiclibrary/ guide/   ← 旧版辅助模块
└── docs/SOP/              ← 本文档体系
```

## 2. migratedev 包结构（按层）
