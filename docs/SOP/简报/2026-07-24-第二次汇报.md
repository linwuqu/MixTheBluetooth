## 本周主要做的事情
1. 本来计划是将后续几个章节进行完善的，但是考虑到后续章节涉及蓝牙输入输出流、本地缓存、远端连接等操作，先把蓝牙、本地、远端端口建设好可能更加清晰，而且可以进一步验证后续合理性。
2. 蓝牙端口相关的实践：完整的阅读了bluetoothlibrary，总体上这个库比较清晰：
    - AllBluetoothManage作为经典蓝牙和Ble蓝牙的统一管理器
    - DeviceModule作为sdk封装的蓝牙data class
    - IBluetooth是暴露的11个接口
    - 因为目前的设备主要是Ble蓝牙 所以我主要看了Ble蓝牙的部分
        - BleBluetoothManage作为外部通信建立管理器 实现了四大重要的业务代码：scanBluetooth connectBluetooth stopScan disConnectBluetooth 实现Ble蓝牙的链路关系建立
        - BluetoothLeService作为内部GATT数据库建立管理器 这里首先介绍下GATT表 它相当于蓝牙设备的驱动 记录了包括设备信息、厂商信息、硬件自定义功能等 就比如说一个蓝牙耳机连接上以后 想要从哪个channel进行数据收发都是记录在这个表中 
            - GATT表的结构可以大致理解为 Service-Characteristic-Descriptor（服务-特征-描述符）服务类似于特征集合 特征类似于结构体 数据收发都是写入读出这里的字段（描述符） 对于自定义的Service使用128位的uuid进行记录
            - 在汇承的蓝牙设备中 首先硬件设备在广播时（连接前）会发送暴露的Service uuid：0xFFE0 同时其公司id是0x4458 所以我设置了一个filter 可以根据这两个信息进行硬件的筛选
            - 对于暴露出来的Service uuid：0xFFE0 通过连接发现完整的uuid为0x0000ffe0-0000-1000-8000-00805f9b34fb
            - BluetoothLeService实现了基本上所有BluetoothGattCallback(android.bluetooth)的所有回调 这里以重要的几个来讲
            - 前面BleBluetoothManage完成了外部连接 建立起了完整信道 但是对于设备发现业务（GATT表获取）onServicesDiscovered 写特征业务onCharacteristicWrite 写描述符业务onDescriptorWrite 连接业务onConnectionStateChange 都没有具体实现 这些都放在BluetoothLeService中进行了实现 同时这两个文件是在不同的线程中进行的（BleBluetoothManage连接时建立 Activity生命周期销毁 BluetoothLeService GATT表建立后一直存在 蓝牙耳机听音乐可以后台就是这个原理） 二者需要进行通信和回调沟通使用的是downloadBinder和mDataHandler
3. 本地端口相关的实践：主要是做了Auth部分Session SharedPreferences存储 同时使用了AES-GCM加密方式 具体做法是先将拿到的原始数据进行json化 然后进行加密 再编码成文本 最后以键值对的形式存入SP
4. 远端端口相关的实践：主要是做了Auth部分认证的完整链路 这里的主要思路是：
    - 在APP启动时 我们将状态机的初始化状态设置为Idle 同时我们所需要的业务是1. 登录 2. 注册 3. 已有Session后自动核验是否有效进行自动登录
    - 其中前两个是用户主动发送Intent实现的 对于自动登录这边的实现方式是在UI建立后的生命周期内 主动的发送一条AppStart Event
    - 状态机 `reduce(State: Idle, Event: AppStart) -> NewState: RestoringSession + Effect: ReadSession` 这样的形式进行用户无感的自动登录(完整状态转移和后续操作见SOP第一章文档)
    - 然后对于登录和注册两个表单业务是使用retrofit作为client将data class转换成Http请求发送的（这里涉及一个TODO：目前Http请求在内容上是明文 wireshark等抓包工具是可以看到完整字节数据的 为了保证安全性之后会对其进行加密 会参考B站大会员在番剧上的高保密、快速编解码技术）
    - 目前包含的请求有：
        ```kotlin
        @POST("/api/account/v1/login")
        suspend fun login(@Body request: LoginRequest): ServerResponse<String>

        @POST("/api/account/v1/register")
        suspend fun register(@Body request: RegisterRequest): ServerResponse<AccountDto>

        @GET("/api/account/v1/detail")
        suspend fun detail(@Header("token") token: String): ServerResponse<AccountDto>
        ```
